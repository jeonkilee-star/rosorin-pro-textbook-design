# 교재 디자인 시안

`ROSOrin_Pro_교재_디자인_삼안.html` 파일을 더블클릭해서 브라우저로 열면 됩니다. 인터넷 연결이 필요합니다(구글 폰트 CDN 사용).

## 내용

레슨 5개 × 디자인 3안 = 15개 조합을 한 화면에서 비교할 수 있는 시안입니다. 실제로 확정된 최종 교재가 아니라 **방향을 고르기 위한 프로토타입**입니다.

- **레슨**: 00-2 전원·충전·초기부팅 / 02-1 ROS2 첫걸음 / 03-1 첫 이동 명령(cmd_vel) / 09-1 로봇팔 첫 동작(실물 사진·결과 기록 포함) / 03-2 바퀴 전방향 테스트(전진·평행이동·회전·대각선)
- **디자인**: A. NCS 공식 학습모듈형 · B. 메이커 실습 가이드형(Adafruit/Raspberry Pi 스타일) · C. 하이브리드형

09-1(로봇팔)은 `WebManual_KR`에 이미 받아둔 Hiwonder 공식 매뉴얼(8장 로봇팔) 실물 사진과, 7·13장 공식 예제에 실제로 쓰인 `/servo_controller` 토픽·`ServosPosition` 메시지·`set_servo_position()` 헬퍼 함수를 그대로 가져와 만들었습니다 — 서보 ID(1,2,3,4,5,10)가 어느 관절인지 라벨링된 사진을 학습목표보다 먼저 보여주도록 구성했습니다.

03-2(바퀴)는 공식 매뉴얼 2.2절의 메카넘 휠 기구학 다이어그램과, 2.1.5절에 확인된 `linear.x` 권장 범위(−0.6~0.6 m/s)·`angular.z` 부호-방향(+ 좌회전/− 우회전)을 그대로 썼습니다. 다만 `linear.y`(좌우 평행이동)의 부호가 실제로 어느 방향인지는 공식 문서에 없어서, 코드에 단정해 넣지 않고 학생이 직접 테스트해 기록표에 적도록 설계했습니다.

## 인쇄

상단 "🖨 인쇄" 버튼 또는 Ctrl+P. A4, 여백 16mm(위아래)/14mm(좌우) 기준으로 맞춰뒀고, 화면에 보이는 조합 1개만 인쇄됩니다. Design B는 화면에서는 다크 톤이지만 인쇄 시 흰 배경으로 자동 전환됩니다.
